## 一、手机号处理方式

1. 编码手机号用到的工具类：

```java
public class PhoneCompressorBase95 {

    private static final int BASE = 95;
    private static final int LENGTH = 6;
    private static final char ASCII_MIN = 32; // 空格
    private static final char ASCII_MAX = 126;

    // 压缩
    public static String compress(String phoneNumber) {
        if (phoneNumber == null || phoneNumber.length() != 11 || !phoneNumber.matches("\\d+")) {
            throw new IllegalArgumentException("必须是11位数字");
        }

        long number = Long.parseLong(phoneNumber);
        if (number < 10000000000L || number > 99999999999L) {
            throw new IllegalArgumentException("手机号超出范围");
        }

        char[] chars = new char[LENGTH];
        for (int i = LENGTH - 1; i >= 0; i--) {
            int remainder = (int) (number % BASE);
            chars[i] = (char) (ASCII_MIN + remainder);
            number /= BASE;
        }

        return new String(chars);
    }

    // 解压
    public static String decompress(String compressed) {
        if (compressed == null || compressed.length() != LENGTH) {
            throw new IllegalArgumentException("必须是6字符的字符串");
        }

        long number = 0;
        for (int i = 0; i < LENGTH; i++) {
            int value = compressed.charAt(i) - ASCII_MIN;
            if (value < 0 || value >= BASE) {
                throw new IllegalArgumentException("字符不在Base95范围");
            }
            number = number * BASE + value;
        }

        return String.format("%011d", number);
    }

    public static void main(String[] args) {
        String phone = "13812345678";

        String encoded = compress(phone);
        System.out.println("压缩结果: " + encoded);

        String decoded = decompress(encoded);
        System.out.println("解压还原: " + decoded);
    }
}
```

2. 处理手机号


## 二、发送的内容处理方式

### 高配

- 音频文件（wav）经过模型，会返回编码结果

* 编码结果：
    * `codesS` (Long): 编码数据大小。
    * `codes` (LongArray): 编码序列。

- 编码结果的处理

```kt
val textHex = codesS.convertToHex(4)
// 将音频数据转换为十六进制字符串
val audioHex = bytesStringToHex(codes)
```

- 工具类

```kt
fun String.convertToHex(padLeft: Int = 4): String {
    val num = this.toLongOrNull() ?: throw IllegalArgumentException("非数字字符串: $this")
    var hex = java.lang.Long.toHexString(num).uppercase(Locale.getDefault())
    if (hex.length < padLeft) hex = hex.padStart(padLeft, '0')
    if (hex.length % 2 != 0) hex = "0$hex"
    return hex
}

// 将 List<Any>（元素可为 Number 或可解析为 Long 的 String）转为拼接的十六进制（每个元素宽度 4，零填充，大写）
fun bytesStringToHex(bytes: List<Any>): String {
    return bytes.joinToString(separator = "") { elem ->
        val v: Long = when (elem) {
            is Number -> elem.toLong()
            is String -> elem.toLongOrNull() ?: throw IllegalArgumentException("非数字元素: $elem")
            else -> throw IllegalArgumentException("不支持的元素类型: ${elem::class}")
        }
        String.format(Locale.getDefault(), "%04X", (v and 0xFFFF))
    }
}

```

## 三、信息头处理
- 

- 高配设置信息头

```kt
var body = "${0}$content"
//  按 UTF-8 编码取字节
val bytes = body.toByteArray(Charsets.UTF_8)

//  强制把第一个字节改为 0000 0001
bytes[0] = 0x01.toByte()

//  再按 UTF-8 解码回字符串
val modified = String(bytes, Charsets.UTF_8)
```

- 低配设置信息头

